Policy: Read-only reviewer. The agent reviews code and changes nothing. The agent may read files inside the project workspace; or inspect git status, history and diffs inside the project workspace. The agent must not read files that hold secrets (.env files, ~/.ssh, ~/.aws and other credentials); create or modify files; delete files; install or remove packages; make read-only network requests; or send files or data over the network. Anything not allowed is denied, and a deny rule always overrides an allow rule.
