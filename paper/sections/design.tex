\section{GateProbe}\label{sec:design}

\tool{} is a Python package and CLI. Data flows through five components.

\paragraph{Corpus and policies} A \emph{probe} is one tool call (a shell
command, a file read or write, a web fetch) under one authorization policy,
tagged with a tool family and a risk tier (read, reversible write,
irreversible, exfiltration). Each policy is written once as allow and deny
rules over actions and scopes, then rendered four ways (YAML, JSON, prose,
bullets), so a change of format can be tested like any other rewrite.

\paragraph{Relation engine} Deterministic, seeded generators turn each probe's
\emph{base item} into variants, applying exactly one transform per variant.
Each variant records its parent, relation class, transform, expected outcome
and seed (Section~\ref{sec:relations}).

\paragraph{Gate adapters} Every gate implements one contract: a policy
rendering, a tool call, context text and answer labels go in.
A verdict
(allow, ask, deny), a block probability $p_\mathrm{block}$, the raw response,
the pinned model id, latency and cost come out. Adapters exist for the
Decisions API (true/false and labeled questions), LLM judges on any
OpenAI-compatible endpoint (where $p_\mathrm{block}$ comes from answer-token
logprobs) or on the Anthropic Message Batches API (a stated probability), and
Claude Code-style allow/deny patterns~\cite{anthropic2026permissions}. A new
vendor is one file.

\paragraph{Runner} Each item is sent $R=3$ times. Every response is stored
under a hash of the gate, the pinned model, the exact request bytes and the
repeat index, so repeats are real calls and a rerun or a reviewer's replay
needs no API key. Retries back off exponentially, and a per-gate dollar cap is
checked before every call.

\paragraph{Analysis and outputs} Scoring follows rules fixed before any run
(Section~\ref{sec:relations}). \texttt{gateprobe analyze} writes the tables as
CSV, \texttt{report} renders a self-contained HTML page with flip examples
before and after, \texttt{ci} fails a pipeline on a significant excess, and
\texttt{hook} shows the gate's verdict on a live Claude Code
call~\cite{anthropic2026hooks}.
