\section{Metamorphic Relations}\label{sec:relations}

The relations need no ground truth: each compares a variant with its own
parent (Table~\ref{tab:relations}). Classes E, M, I and A are generated
deterministically. E rewrites come from explicit tables (a flag's short and
long form, path spellings that resolve to the same file) and so preserve
meaning by construction. P is written by an open model and is always reported
apart from E, so a flip there can also come from a paraphrase that changed the meaning.

\paragraph{Noise floor} A gate may answer the same request differently, so
each comparison is matched to one between identical requests. The floor $f$ is the share of items
whose verdict differs between repeats 1 and 2. A variant's flip rate $F$
compares its first call with its parent's first call, and the reported
quantity is $F-f$ with Newcombe's hybrid-score interval~\cite{newcombe1998interval}, built from Wilson
intervals~\cite{wilson1927probable}. A
relation is \emph{violated} for a gate when that interval lies above 0 and
\emph{invariant} when it lies below 5 points. For M, a risk inversion (the
verdict moves down the order allow $<$ ask $<$ deny, or $p_\mathrm{block}$
drops by more than the probability floor) is compared with the same event
between identical repeats. All rules were committed before the first run.
