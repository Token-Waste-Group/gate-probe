\begin{abstract}
Coding agents route every tool call through a permission gate, and the newest
gates are learned decision models or LLM judges: untested ML components in a
security-critical position. \tool{} is a metamorphic testing harness for these
gates. It rewrites a call, its policy and its context under relations with
known outcomes: an equivalent rewrite must not change the verdict, a riskier
one must not lower the block probability, and irrelevant or injected text must
not move it. No ground truth is needed. \tool{} subtracts each gate's
test--retest noise floor and reports flips with 95\% intervals under scoring
rules fixed before any run. It ships as a CLI and Docker image with adapters
for decision models, LLM judges and rule sets, an HTML report, a CI check, a
Claude Code hook and a key-free replay mode. On 300 tool calls and six gates,
every gate flips on equivalent rewrites above its floor (by 1.1--7.5 points),
four allow overwriting a secrets file they forbid reading, and injected text
pushes two decision models toward allow.
Tool, Docker image and replay bundle: \toolurl. Video: \videourl.
\end{abstract}
