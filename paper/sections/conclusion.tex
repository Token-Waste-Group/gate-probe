\section{Conclusion}\label{sec:conclusion}

\tool{} tests permission gates the way a security component should be
tested: against rewrites whose right answer is known without an oracle. All
six gates we tried contradict themselves on equivalent inputs. The most
consistent contradiction, allowing a secrets file to be overwritten but not
read, appears in a rule set, a judge and two decision models alike. Future
work adds an open-weight judge (Gemma~4~\cite{google2026gemma4} on
vLLM~\cite{kwon2023efficient}), validates paraphrase pairs by running both
commands in a sandbox, and runs the planned user study.
