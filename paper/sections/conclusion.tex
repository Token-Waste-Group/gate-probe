\section{Conclusion}\label{sec:conclusion}

\tool{} tests permission gates against rewrites whose right answer is known
without an oracle. All
seven gates we tried contradict themselves on equivalent inputs. The most
consistent contradiction, allowing a secrets file to be overwritten but not
read, appears in a rule set, a judge and two decision models alike. Future
work extends the sandbox check to commands that need a network and runs the
planned user study.
